# سيرفر إشعارات واتساب — هِمَم (Render)

سيرفر بسيط يرسل إشعار كل طلب جديد لرقم المتجر، ورسائل تحديث حالة الطلب للزبائن.
**لا يحتاج أي متغيرات (Environment) ولا توكن ولا قرص Disk.**

## خطوات النشر على Render

1. ارفع ملفات هذا المجلد كما هي على مستودع GitHub (أو استبدل ملفات مستودعك الحالي بها).
2. في Render: **New › Web Service** › اختر المستودع:
   - Build Command = `npm install`
   - Start Command = `npm start`
   (أو New › Blueprint ليقرأ `render.yaml` تلقائياً).
3. لا تضف أي شيء في Environment. إن كان عندك سابقاً `AUTH_DIR` أو `SERVICE_TOKEN` فلا مشكلة — السيرفر يتجاهلها، ويمكنك حذفها.
4. بعد اكتمال النشر انسخ رابط الخدمة، مثل: `https://xxx.onrender.com`
5. في لوحة تحكم المتجر › **واتساب** › سيرفرات واتساب: أضف اسم السيرفر + الرابط ثم **حفظ السيرفر** و**تفعيل**.
6. اضغط **اختبار** وسيظهر رمز QR — امسحه من واتساب › الأجهزة المرتبطة › ربط جهاز.

## ملاحظات
- السيرفر يحفظ جلسة واتساب في أول مجلد قابل للكتابة (`/data/auth` إن وُجد قرص، وإلا مجلد `auth` داخل المشروع).
- السيرفر يوقظ نفسه كل 10 دقائق حتى لا ينام على الخطة المجانية.
- على الخطة المجانية قد تحتاج لمسح QR مرة أخرى بعد كل نشر جديد (Deploy) فقط.

زر **إعادة تهيئة** يعيد الاتصال مع الاحتفاظ بالجلسة. زر **تسجيل خروج وإظهار QR** يحذف الجلسة عمداً ويولّد رمزاً جديداً.

## نقاط النهاية
- `GET /status` — حالة الاتصال + رمز QR
- `POST /send` — `{ "to": "96894913233", "message": "..." }`
- `POST /restart` — إعادة تهيئة الاتصال مع الاحتفاظ بالجلسة
- `POST /logout` — تسجيل خروج وحذف الجلسة وتوليد QR جديد
