# سيرفر إشعارات واتساب — هِمَم (Render)

سيرفر بسيط يرسل إشعار كل طلب جديد لرقم المتجر، ورسائل تحديث حالة الطلب للزبائن.

## خطوات النشر على Render

1. أنشئ مستودع (Repository) جديد على GitHub وارفع فيه ملفات هذا المجلد كما هي.
2. ادخل على https://dashboard.render.com › **New** › **Blueprint** واختر المستودع.
   سيقرأ Render ملف `render.yaml` وينشئ الخدمة والقرص الدائم تلقائياً.
   (أو: New › Web Service › اختر المستودع، Build Command = `npm install`، Start Command = `npm start`).
3. في **Environment** أضف:
   - `SERVICE_TOKEN` = توكن سري تختاره أنت (نفسه ستضعه في لوحة التحكم).
   - `AUTH_DIR` = `/data/auth`
4. **القرص الدائم (Disk) — خطوة إلزامية:** من إعدادات الخدمة › **Disks** › Add Disk:
   - Mount Path = `/data`
   - Size = 1 GB
   بدون القرص تُحذف جلسة واتساب عند كل إعادة تشغيل أو نشر وستحتاج لمسح QR من جديد.
   ملاحظة: الأقراص الدائمة تعمل على الخطط المدفوعة في Render (Starter فأعلى)، والخطة المجانية تنام بعد فترة خمول.
5. بعد اكتمال النشر انسخ رابط الخدمة من أعلى الصفحة، مثل:
   `https://xxx.onrender.com`
6. في لوحة تحكم المتجر › **واتساب** › سيرفرات واتساب: أضف اسم السيرفر + الرابط + التوكن ثم **حفظ السيرفر** و**تفعيل**.
7. اضغط **اختبار** وسيظهر رمز QR — امسحه من واتساب › الأجهزة المرتبطة › ربط جهاز.

زر **إعادة تهيئة** يعيد الاتصال مع الاحتفاظ بالجلسة. زر **تسجيل خروج وإظهار QR** يحذف الجلسة عمداً ويولّد رمزاً جديداً.

## نقاط النهاية
- `GET /status` — حالة الاتصال + رمز QR (يتطلب Authorization: Bearer TOKEN)
- `POST /send` — `{ "to": "96894913233", "message": "..." }`
- `POST /restart` — إعادة تهيئة الاتصال مع الاحتفاظ بالجلسة
- `POST /logout` — تسجيل خروج وحذف الجلسة وتوليد QR جديد
